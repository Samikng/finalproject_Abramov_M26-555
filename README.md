# ValutaTrade Hub

Консольное приложение — платформа для отслеживания и симуляции торговли фиатными
и криптовалютами.

## Принцип работы

Система состоит из двух частей:

- **Core Service** — командный интерфейс, пользователи, портфели и сделки;
- **Parser Service** — получение курсов валют из внешних API.

**Пользователи.** При регистрации пароль хешируется (SHA-256 с солью) и
сохраняется в `data/users.json`, пользователю создаётся пустой портфель в
`data/portfolios.json`. Операции с портфелем доступны только после входа.

**Портфель.** У каждого пользователя есть набор кошельков, по одному на валюту.
Покупка USD пополняет USD-кошелёк. Покупка другой валюты списывает её стоимость
по текущему курсу с USD-кошелька, продажа зачисляет выручку на USD-кошелёк.
Кошелёк покупаемой валюты создаётся автоматически. Баланс не может уйти в минус:
при нехватке средств сделка отклоняется.

**Курсы.** Parser Service запрашивает криптовалюты (BTC, ETH, SOL) у CoinGecko и
фиатные валюты (EUR, GBP, RUB) у ExchangeRate-API. Последний курс каждой пары
сохраняется в `data/rates.json`, а все измерения — в историю
`data/exchange_rates.json`. Курсы хранятся относительно USD, курс между двумя
другими валютами считается через USD.

**Актуальность курсов.** Курс считается свежим 5 минут. Если он устарел, приложение
само запрашивает обновление у Parser Service. Если обновить не удалось,
используется последний известный курс с предупреждением.

**Ошибки и логи.** Недостаточно средств, неизвестная валюта и сбой внешнего API
обрабатываются как отдельные исключения и выводятся пользователю понятными
сообщениями. Регистрация, вход, покупка и продажа записываются в `logs/actions.log`,
работа Parser Service — в `logs/parser.log`.
