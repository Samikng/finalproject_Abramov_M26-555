# ValutaTrade Hub

Консольное приложение для симуляции торговли фиатными и криптовалютами.

## Принцип работы

Приложение состоит из Core Service (CLI, пользователи, портфели, сделки) и
Parser Service (получение курсов из внешних API).

Пароль пользователя хранится в виде SHA-256 хеша с солью в `data/users.json`,
портфели — в `data/portfolios.json`.

Покупка валюты списывает её стоимость с USD-кошелька, продажа зачисляет выручку
на USD-кошелёк. Покупка USD пополняет счёт.

Курсы криптовалют берутся из CoinGecko, фиатных валют — из ExchangeRate-API.
Последние курсы хранятся в `data/rates.json`, история — в `data/exchange_rates.json`.

Операции пользователей логируются в `logs/actions.log`, работа Parser Service —
в `logs/parser.log`.
